# Theatre Screening Management System

## Project Overview
The Theatre Screening Management System is a DBMS mini-project designed to organize and manage theatre-related information, including theatres, screens, movies, shows, seats, customers, bookings, payments, and tickets.

## Objectives
- To design a structured relational database for theatre screening management.
- To establish relationships between database entities using primary and foreign keys.
- To manage theatre, movie, customer, booking, payment, and ticket information efficiently.

## Technologies Used
- **Database Management System:** MySQL
- **Query Language:** SQL
- **Database Design Tool:** MySQL Workbench

## Database Tables
The project includes the following tables:
1. Theatre
2. Screen
3. Movie
4. ShowDetails
5. Seat
6. Customer
7. Booking
8. Payment
9. Ticket

## Project File
- `TheatreManagement.sql` — SQL file containing the database implementation.

## How to Use
1. Install MySQL and open MySQL Workbench.
2. Open the `TheatreManagement.sql` file.
3. Execute the SQL statements to create and work with the database.
4. Run the relevant queries to explore the database operations.
